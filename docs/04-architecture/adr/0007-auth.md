# ADR-0007: Authentication

Status: **Accepted (draft)** · Date: 2026-11-06

## Decision
- **Email + password** (argon2id, via `@node-rs/argon2`) and **magic link** (SMTP via Nodemailer). No SSO of any kind (VISION D2).
- **Server-side sessions** in Postgres. The cookie `surface_session` is a random 256-bit token (only its hash is stored), HTTP-only, Secure, SameSite=Lax, with a 30-day sliding expiry.
- **CSRF:** a double-submit token on cookie-authenticated POSTs. The API and MCP use bearer API keys, so CSRF does not apply to them.
- **Rate limits:** 5 failed logins per 15 minutes per account and per IP, then a temporary lockout.
- **No SMTP:** magic link and email reset are hidden. Admins generate one-time reset and invite links instead.
- **API keys:** `sfc_` + 32 random bytes. Only the hash is stored, and the prefix is shown for identification.

## Consequences
+ Simple, dependency-light, and works completely offline from the internet.
− 2FA is v2 (FR-AUTH-11).
