In Surface today

The core of a modern tracker, without the bloat.

Teams, workflows, issues and the editor are built. Views, cycles and projects are next on the roadmap.

Issues with real IDs

Every issue gets a team key and number, like ENG-142, that is never reused. Press C anywhere to create one.

Workflows per team

Custom statuses in fixed categories, workspace and team labels with label groups, and estimates on the scale you like.

A real editor

Markdown shortcuts, slash commands, checklists, and code blocks with syntax highlighting, in descriptions and comments.

Comments and reactions

Threaded replies, resolvable threads and emoji reactions, synced live to everyone on the issue.

Attachments

Paste, drop or upload files and images, with previews. Files stay on your server, within the size limit you set.

History you can trust

Every property change is recorded with who made it and when. Nothing changes without a trace.

Delete without fear

Deleted issues wait 30 days in Recently deleted. Finished work archives itself, and anything archived can come back.

Command menu

Press ⌘K or Ctrl+K for every action the app has, aware of the issue you are on. Press ? for every shortcut.

Self-host

Up in fifteen minutes. Then it stays out of your way.

One Docker image and PostgreSQL on a Linux machine you own. Migrations run on start, health checks are built in, and upgrading is a new tag and a restart.

~/surface
$ git clone --depth 1 https://github.com/s-ayush/surface.git
$ cd surface/docker && cp .env.example .env
# set SURFACE_URL and two secrets in .env (see the guide)
$ docker compose --profile proxy up -d
✔ Container surface-db-1    Healthy
✔ Container surface-app-1   Healthy
$ docker compose logs app | grep setupUrl
Surface is not set up yet. Open https://…/setup?token=…

FAQ

Questions, answered plainly.

Is Surface really free?

Yes. Surface is MIT licensed with no paid tier, no enterprise edition and no seat limits. You pay only for the machine you run it on.

How is Surface different from Linear?

Surface borrows the ideas that make Linear fast: a local copy of the workspace, keyboard shortcuts for everything and a command menu. The difference is that Surface is open source and runs on your own server. Surface is an independent project, not affiliated with Linear.

Can my team use it today?

Surface is in alpha. Teams, issues, workflows, the editor, comments, attachments and archive are built and tested. Views, cycles and projects come next. Try it with your team, and follow the backup guide until scheduled backups arrive.

What do I need to run it?

A Linux machine with Docker, 2 vCPU, 2 GB of RAM and 20 GB of disk. PostgreSQL is bundled, or you can use your own PostgreSQL 17 or newer. For HTTPS, the install guide includes a ready Caddy setup.

Does it work offline?

Yes. Everything already synced stays readable offline, and your edits queue up and apply when you reconnect. Content you have never opened shows as available when online.

Does Surface send my data anywhere?

No. Surface has no telemetry, no analytics and no update checks. The only outbound connection it ever makes is to the mail server you configure, if you configure one.

How many people can use it?

Surface is built for teams of 10 to 50 people, and its performance budgets are set for 50 active users and 100,000 issues. There is no hard cap above that.

Can I import from Jira, Linear or GitHub?

CSV import and export is on the roadmap. Surface does not plan built-in integrations with other services.

How do I contribute?

Read CONTRIBUTING.md in the repository, then open an issue or a pull request. Report security problems privately, as SECURITY.md describes.
